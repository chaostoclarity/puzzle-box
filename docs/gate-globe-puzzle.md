# Milestone 2 gate: a puzzle added from a written description

## The description (as a designer would write it)
"Wren's globe should turn. Each touch spins it a quarter turn. When the mark scratched into the
South Pacific faces you, a little drawer in the stand pops open with a torn page from Wren's diary.
It's optional, it only works once the lamp is lit (it's on the dark wall), and it should hint at
where the cabinet came from."

## What it took
- Art: four views of the globe plus the open-drawer view, added to tools/make_room_art.py.
- Data: one puzzle entry, one binding, one interaction and two walkthrough lines in data/rooms/room1_study.json.
- Code: none for the puzzle itself. (The kit gained one general option: cyclers can swap pictures without the spin animation.)
